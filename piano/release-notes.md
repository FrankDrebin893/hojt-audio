## Install

Download the `win-x64.zip` below, unzip it, and run `PianoMidiVisualizationApp.exe`. There is no installer, and .NET doesn't need to be installed. Requires 64-bit Windows 10 or 11.

- **A stage piano is built in** and plays from the first launch, with no download. For a sampled piano, download any `.sf2` or `.sfz` and pick it in **View → Settings…** (Soundbank Library). Free options: [GeneralUser GS](https://schristiancollins.com/generaluser.php) or [Salamander Grand Piano](https://sfzinstruments.github.io/pianos/salamander).
- **Windows may say "Windows protected your PC"**, because the app isn't code-signed yet. Click **More info**, then **Run anyway**.
