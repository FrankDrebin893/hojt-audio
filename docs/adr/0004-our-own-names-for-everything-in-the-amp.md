# All amps and cabinets are our own designs, with our own names

The Guitar Amp's amps, cabinets and effects carry names of our own (Klar, Brøl, Torden...). No real maker's name, trademark or circuit name appears anywhere: code, comments, docs, commit messages, issues. `plugins/amp/tests/rules.rs` checks this against a list kept as hashes, so the list of forbidden names is not itself spelled out in the repository.

## Consequences

An idea or a report that says "like the X amp" is written up in our own terms before it reaches a spec or code.
